## Overview

**RetailFlow** is a proposed digital solution designed to help small retail businesses manage products, inventory, sales and basic business performance information from one simple system.

This repository contains the complete **Project Plan** prepared for the **TSAcademy Junior Project Manager Assignment**.

| Item | Detail |
|------|--------|
| **Industry** | Information Technology / Digital Business Solutions |
| **Project Duration** | 12 October 2026 – 15 January 2027 (14 calendar weeks) |
| **Delivery Approach** | Hybrid Agile |
| **Authorised Budget** | ₦8,950,500 |
| **Current Version** | **1.1** (Reviewed & Enhanced) |
